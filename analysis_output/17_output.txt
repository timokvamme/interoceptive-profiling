THE PROBLEM
-----------
12_sem_pathway_analysis.R z-scores every variable and then forms the product
term ias_x_iats = ias_z * iats_z. The product of two z-scored variables is
NOT itself unit-variance: SD(ias_z * iats_z) = 1.056073 in this sample.
Consequently, for the interaction paths only, the fully standardized
coefficient differs from the unstandardized one by that factor:
  std.all = est * 1.056073
For every non-interaction path the two metrics coincide to 3 decimals,
because those predictors and all outcomes are already z-scored.
lavaan attaches the UNSTANDARDIZED Wald p-value to std.all, which is why the
p-value is identical in both columns and the discrepancy went unnoticed.

Verification of the published numbers, from this re-fit:
  IAS x IATS -> Somatic, unstandardized est = -0.089048 (SE 0.029999)
  IAS x IATS -> Somatic, std.all           = -0.094041 (delta SE 0.031494)
  ratio std.all / est                      = 1.056073
  Wald p (identical for both)               = 0.002994
  delta-method 95% CI, unstandardized      = [-0.1478, -0.0303]
  delta-method 95% CI, standardized        = [-0.1558, -0.0323]

The published interval [-0.146, -0.023] is centred on -0.0845, i.e. on the
UNSTANDARDIZED point estimate, while the published point estimate -0.091 is
the STANDARDIZED one. The manuscript therefore pairs a standardized estimate
with an unstandardized interval. That is the defect these numbers replace.

RECOMMENDATION
--------------
Report the FULLY STANDARDIZED (std.all) metric throughout, with percentile
bootstrap CIs computed on the standardized quantity, i.e. the right-hand
block above. Reasons:
  1. It is the metric the main text already quotes (-0.345, +0.314, +0.444,
     -0.095, -0.091), so only the intervals change, not the headline values.
  2. It is the only metric in which the interaction term is on the same
     footing as the main effects; the unstandardized interaction is scaled
     by the arbitrary SD of the product term (1.0561).
  3. Standardized betas are what the profile-level interpretation rests on.
Supplementary Table 1 should then be regenerated in the same metric, or
explicitly labelled 'unstandardized' with the unstandardized CIs from the
left-hand block. Do not mix the two, which is the present state.
